### 你好，我是 Shuling 👋

在 [NUDT](https://www.nudt.edu.cn/) 做计算机视觉，主要绕着**人体解析**、**图像色彩**和**生成结果怎么评**这几件事打转。
业余时间喜欢把这些能力接进日常：记账、抓取、日报，能自动的就别手动。
折腾过程写在 **[shulingtang.github.io](https://shulingtang.github.io)**。
